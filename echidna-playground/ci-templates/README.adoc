= Playground CI templates (not executed)

These workflow files were under `echidna-playground/.github/workflows/`.
GitHub reads workflows only from the repository-root `.github/workflows/`, so
they never ran. They were moved here (ultraplan Phase 0.6, tracking issue
#416) so that they cannot be mistaken for active CI.

They are kept as templates. Before any of them is revived, check it against the
root workflow of the same concern. Most of them duplicate one. Revive a file by
moving it to the root and removing the duplicate. Do not leave a copy here that
looks like CI.

`mirror.yml` was removed (2026-10-14): the root `.github/workflows/mirror.yml`
covers mirroring through the standards reusable workflow, and the template's
Radicle job installed by piping a remote script to `sh`.
