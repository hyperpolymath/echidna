== ECHIDNA Environment Variables

*Status*: canonical reference. Last revised: 2026-11-04.

Every environment variable the system reads, with type, default, and the
files that consume it. If you add a new env var, update this table in
the same PR.

=== Interface listeners

Each listener is a separate binary. GraphQL defaults to 8082 from 2026-11-04,
removing its collision with the core server on 8081. See the migration note
in link:../CHANGELOG.adoc[`+CHANGELOG.adoc+`].

[width="100%",cols="20%,20%,20%,20%,20%",options="header",]
|===
|Variable |Type |Default |Used by |Purpose
|`+ECHIDNA_REST_ADDR+` |host:port |`+127.0.0.1:8000+`
|`+src/interfaces/rest/main.rs:142+` |Bind address for the `+echidna-rest+`
binary (`+/api/v1/*+`). Not the core server.

|`+ECHIDNA_GRAPHQL_ADDR+` |host:port |`+127.0.0.1:8082+`
|`+src/interfaces/graphql/main.rs+` |Bind address for `+echidna-graphql+`.
Hostnames remain supported. Invalid values and occupied addresses produce
a startup error instead of a bind panic.

|`+--port+` / `+--host+` (CLI flags, not env)
|host:port |`+127.0.0.1:8081+`
|`+src/rust/main.rs+` |Bind address for `+echidna server+`. There is no
environment override for this one.

|`+APP_PORT+` / `+APP_HOST+` |host:port |`+[::]` / `+8081+`
|`+container/entrypoint.sh+` |Read by the container entrypoint and passed to
`+echidna server+` as flags. The binary itself does not read them.
|===

=== Container & secrets

In `+.containerization/Containerfile.full+`, the following are expected
to be mounted or built into the image rather than passed as env:

* Solver binaries — paths in `+config/solver-manifest.toml+` (with
SHAKE3-512 hashes)
* Guix manifest — `+manifests/live-provers.scm+`
* TLS material — none in default container; HTTPS terminated by reverse
proxy

=== Reading order for new contributors

[arabic]
. Set `+ECHIDNA_ML_API_URL+` and `+VERISIM_URL+` for any local dev
session that touches dispatch or ML paths.
. Set the `+ECHIDNA_*+` training caps only when running
`+just train-cpu+` or `+just eval+` on a constrained host.
. CI secrets (`+FARM_DISPATCH_TOKEN+`, `+VERISIMDB_PAT+`) are
repository-level — no local action needed.
