== Vocabulary

Closed set, `+PROOF-POLICY.adoc+` §5. Machine-readable ledgers use the
lowercase token; prose may use the label.

[width="100%",cols="22%,16%,62%",options="header"]
|===
|Token |Label |Means

|`+proven+` |PROVEN
|Machine-checked with no escape hatch, trust boundary named. A bounded check is
not this row.

|`+proven-with-postulates+` |PROVEN-WITH-AXIOMS
|A kernel checked it and it rests on named necessary axioms, listed here.

|`+tested-only+` |TESTED
|Checked on a bounded or sampled domain; bounds given.

|`+argued+` |ASSUMED
|A stated hypothesis, or a transcription no kernel has checked. Includes "the
CI gate exists and the authors say it passes" when no receipt is cited.

|`+open+` |OPEN
|Not done.
|===

=== Proof Witness Grades (`+PROOF-POLICY+` §8)

The only estate proof grade is the *Proof Witness Grade* of `+PROOF-POLICY+`
§8, written with its prefix: `+PWG-3+` < `+PWG-2i+` < `+PWG-2ii+` <
`+PWG-1+`, with `+PWG-1+` the strongest. The Mathesis brief's "Grade 3/2i/2ii/1"
is superseded by §8 and is not used here.

* PWG grades apply to *theory* theorems only (§8.1). Engineering
  obligations, including every statement about this repository's types,
  functions or wire formats, carry a §5 token and no grade.
* A grade is *derived from receipts*, never asserted (§8.4). `+PWG-3+` needs a
  receipt that records the Agda version, the standard-library pin, the flags
  in force, the import cone, and a comment-aware postulate scan of that cone
  (§8.2, §8.4). A recheck leg counts only when it is kernel-checked *and* its
  statement correspondence is `+RECONCILED+` (§2.2).
* The census below gives counts with their denominator, never a percentage.

== Classification under §1 (owner ruling 2026-11-09)

The owner ruled to apply §1's test strictly: a statement that names a type,
function or wire format of this repository is *engineering*, whatever prover
it is written in. Rust behaviour is verified with Creusot/Pearlite and Verus
on the code (§1.2); a separately written model, in Agda, Lean or Idris 2,
does not establish implementation correctness. Consequences for this file:

* Of the nine meta-checker modules, only `+Receipt.agda+` is theory. The
  other eight model echidna's own trust pipeline and are recorded under
  R4b as engineering models; the Rust obligations they describe are R1's.
* The five Lean files are engineering models of Rust code, not §4
  exceptions (none carries a §4 header record). Their Rust obligations are
  R1's.
* The Idris 2 files under `+verification/proofs/idris2/+` that restate Rust
  behaviour (trust levels, clamp, dispatch) are likewise models; the Idris 2
  ABI package in `+src/abi/+` is Idris 2's proper §1 home (R2a).
* The Rocq/Lean recheck obligation (§2, R5) applies to the theory theorems
  only: `+Receipt.agda+`.

== Not obligations

`+PROOF-POLICY+` §3: "`Corpora that exist to exercise provers are not
obligations. echidna's `+proofs/<prover>/+` trees and similar fixtures are test
material for a multi-prover system and are outside this policy.`"

So the sixteen `+proofs/<prover>/+` directories and `+training_data/+` carry no
row. They exercise parsers and backends. Listing them is deliberate: an absent
row should read as *out of policy*, not *forgotten*. The same holds for
`+archive/logtalk/+` (dead, quarantined) and for `+echidna-playground/+`.

Note the tension with R6 — one artefact in a corpus directory is cited by
`+PROOF-NEEDS+` as covering a real obligation. §3 is why that is a defect in
placement rather than a status question.

== What this file does not do

It is not a release gate and not a CI result. A `+proven+` row here would never
mean "ECHIDNA is verified" — it would mean one named obligation was discharged
by one named tool with its boundary written down. Nothing here vouches for a
prover backend's own soundness.

Two rows are `+proven+` today, R2a and R4a, and each names the kernel, the
receipt and the limit that qualify it. Every other first-party obligation is
`+open+`, and most of the Rust behaviour it concerns sits in R1, waiting on a
Creusot or Verus run. The ten theory theorems are at `+PWG-3+`, derived from the
2026-11-09 cone receipt; they cannot rise above it until R5's Rocq and Lean
legs exist. None of this is an omission.
