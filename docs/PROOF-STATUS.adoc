=== Proof Witness Grades (`+PROOF-POLICY+` §8)

A Proof Witness Grade (`+PWG-3+`, `+PWG-2i+`, `+PWG-2ii+`, `+PWG-1+`; lower is
stronger) counts the independent machine-checked witnesses of a *theory*
theorem. It is not a §5 status token and not a §2.2 correspondence state, and
each record below carries all three separately. It is always written with its
`+PWG-+` prefix; the earlier "Mathesis Grade" wording in this file is retired
because §8 forbids a bare "Grade".

* PWG applies only to theory obligations (§8.1). Engineering proofs (Idris2,
  Creusot/Pearlite and Verus, SPARK) use §5 tokens only and carry no grade.
* A theory theorem below `+PWG-3+` is `+ungraded+`.
* Grades are derived from receipts (§8.4), never asserted. A grade census, if
  published, is a count per grade with its denominator, never a percentage.

== Not obligations

`+PROOF-POLICY+` §3: "`Corpora that exist to exercise provers are not
obligations. echidna's `+proofs/<prover>/+` trees and similar fixtures are test
material for a multi-prover system and are outside this policy.`"

So the sixteen `+proofs/<prover>/+` directories and `+training_data/+` carry no
row. They exercise parsers and backends. Listing them is deliberate: an absent
row should read as *out of policy*, not *forgotten*. The same holds for
`+archive/logtalk/+` (dead, quarantined) and for `+echidna-playground/+`.

Note the tension with R6 — one artefact in a corpus directory is cited by
`+PROOF-NEEDS+` as covering a real obligation. §3 is why that is a defect in
placement rather than a status question.

== What this file does not do

It is not a release gate and not a CI result. A `+proven+` row here would never
mean "ECHIDNA is verified" — it would mean one named obligation was discharged
by one named tool with its boundary written down. Nothing here vouches for a
prover backend's own soundness.

Six rows are `+proven+` today (R2, R4, R9, R10, R11) or `+proven-with-postulates+`
(R3), and each names the kernel, the receipt and the limit that qualify it: R4
carries the `+UnsupportedIndexedMatch+` caveat, R9 the digest-level scope, R10
the model-only scope, and R3 its three Lean core axioms. R1 (Rust) is `+open+`.
One theory theorem is graded: `+Receipt+` at `+PWG-3+`, because both of its
recheck legs (R5) are still `+open+`. Being proven in one kernel is exactly what
`+PWG-3+` means, and a grade is not a discharge of §2 (§8.4.1).
