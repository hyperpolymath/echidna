Mine lexicon candidates across training corpora (flag-only)

Usage: echidna lexicon [OPTIONS] <COMMAND>

Commands:
  scan  Pair theorem names and canonical statement shapes across training corpora and write review candidates as JCS JSON Lines. Every candidate carries `evidence = none`; `data/synonyms/` is never edited
  help  Print this message or the help of the given subcommand(s)

Options:
      --format <FORMAT>  Output format (text, json) [default: text]
  -v, --verbose          Verbose output
      --no-color         Disable colors
  -h, --help             Print help
